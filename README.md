# 🏡 StaySphere – MERN Rental Platform

> 🚀 A full-stack Airbnb-like web application for booking, listing, and managing stays.

---

## 📌 Overview

**StaySphere** is a modern **MERN stack** application that allows users to explore, list, and book rental properties seamlessly.
Inspired by Airbnb, it provides a smooth user experience with secure authentication and real-time data handling.

---

## 🎯 Features

### 👤 User Features

* 🔐 User Authentication (Login / Signup)
* 🔍 Search & filter properties
* 🏠 View property details
* 📅 Book stays
* ❤️ Wishlist / favorites (optional)

### 🏢 Host Features

* ➕ Add new listings
* ✏️ Edit / delete properties
* 📊 Manage bookings

---

## 🧠 Tech Stack

### 🌐 Frontend

* HTML, CSS, JavaScript

### ⚙️ Backend

* Node.js
* Express.js

### 🗄️ Database

* MongoDB (Mongoose)

### 🔐 Authentication

* JWT (JSON Web Tokens)
* bcrypt for password hashing

---
## ⚡ How It Works

1. Users sign up / log in securely
2. Browse listings with filters
3. View property details
4. Hosts can manage their listings
